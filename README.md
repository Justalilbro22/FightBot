# Minecraft Working FightBot

⚔️ FightBot Requirements
💻 Software

Node.js 24+                          
Minecraft Java Edition          
A Minecraft server running on localhost:25565            
Internet connection for installing npm packages

📦 Required Node.js packages 
Run these inside the FightBot folder:

npm install mineflayer

npm install mineflayer-pathfinder

npm install vec3

npm install minecraft-data

FightBot is a PvP training bot designed to fight players.

## 🎮 How to Start

Type in chat:

`START FIGHT`

FightBot will target the player who sent the command and begin fighting.

## 🛑 How to Stop

Type:

`STOP FIGHT`

FightBot will immediately stop fighting and stop moving.

## ⚔️ What FightBot Can Do

FightBot can:

* ⚔️ Fight players with a diamond sword
* 🪓 Switch to a diamond axe when a shield is detected
* 💎 Wear diamond armor
* 🏃 Chase and strafe around players
* 💥 Perform critical attacks
* 🪣 Use lava during combat
* 💧 Place water when it catches on fire
* 🍎 Eat golden apples when its health gets low
* 🎯 Aim at its target while fighting
* 🏆 Say `gg` when it defeats its opponent

## 💬 Commands

`START FIGHT` — Start a fight against you

`STOP FIGHT` — Stop FightBot

## ℹ️ Important

Only use `START FIGHT` when you are ready to fight.

After FightBot defeats you, it will stop fighting and say:

`gg`

Have fun! ⚔️
